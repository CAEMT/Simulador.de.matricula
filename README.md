# SIMULADOR DE MATRÍCULA por Engenharia de Materiais da Universidade Federal de Itajubá (UNIFEI)

Um aplicativo interativo desenvolvido com Streamlit para simular e auxiliar na matrícula de disciplinas do curso de Engenharia de Materiais da UNIFEI.

## Funcionalidades

- **Seleção de Grade Curricular**: Escolha entre diferentes versões de matrizes curriculares (2016, 2023)
- **Período Letivo**: Configure o semestre de destino (Ímpar ou Par)
- **Cálculo de Pré-requisitos**: Sistema inteligente que verifica automaticamente os requisitos de cada disciplina
- **Sugestões de Matrícula**: Recomendações baseadas nas disciplinas concluídas
- **Identificação de Bloqueios**: Mostra disciplinas não ofertadas no período selecionado
